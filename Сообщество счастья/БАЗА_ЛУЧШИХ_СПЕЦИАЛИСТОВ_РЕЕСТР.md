=====

ОТКУДА БРАТЬ ИМЕНА — НАПОМИНАНИЕ (подробности в ПРОФЕССИОНАЛЬНЫЙ_ТРЕК_КОВЧЕГА, Блок 5 и 7)

1. Врачи — через сеть ТЕЛЕДОК, готовый канал.
2. Учителя — через профессиональные рейтинги и родительские рекомендации.
3. Электрик/сантехник/строитель/сисадмин — через рекомендации уже вступивших участников пермского клуба («у вас отличный мастер — пригласите его на квиз»).
4. Не искать с нуля — начинать с тех, кого уже лично знают и рекомендуют Сергей, Наташа и первые участники клуба «Территория контакта».

=====

ЗАДАЧИ / ТОЧКИ ДЕЙСТВИЯ

→ Заполнить первые 10-15 строк реестра именами, которых Сергей и Наташа уже знают лично — не ждать полного списка профессий.
→ При каждой новой встрече пермского клуба спрашивать участников: «кого из вашего круга — врача, мастера, учителя — стоит сюда пригласить».
→ Обновлять статус по мере продвижения человека по воронке (не приглашён → активный участник ячейки).
